# Archived personal implementations

These files are retained for reference and possible reuse. They are not loaded
by the current source configuration.

- `local/`: all 32 personal QML/JavaScript sources before the upstream import.
- `base/` and `upstream/`: old baseline and incoming counterparts.
- `conflicts/`: original text-conflict output; not executable QML.
- `retired-sources/`: disconnected integration/component implementations.
- `standalone/`: previous animated-wallpaper Python helper and systemd unit.
- `tests/`: historical mpvpaper live test, requiring the old setup.
- `previous-patches/`: original personal feature patches before the update.
- `retired-baselines/`: baseline files no longer referenced by active custom hooks.
- `resolution.json`: conflict history and the decision to accept upstream.

See the repository `UPSTREAM-MERGE.md` for active features and activation status.
